# Visual review

Visual evidence - what a render proves, which states must be inspected, how
observations are recorded and which groups remain unrendered - is owned by
[visual consistency](../../design-system/references/visual-consistency.md#evidence)
in the design-system skill. Visual intent and the usage/state inventory are owned
by [brand-design](../../brand-design/references/usage-and-states.md); acceptance
by its [design acceptance table](../../brand-design/references/workflow-and-review.md#design-acceptance);
artwork by [illustrations](../../illustrations/SKILL.md#completion).

A reviewer applies those owners through the `design-reviewer` agent or directly;
this file adds no rule of its own.
